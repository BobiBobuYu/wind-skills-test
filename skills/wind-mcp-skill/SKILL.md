# Wind 万得金融数据

## 核心能力

通过 `search` 从持续扩展的 Wind 工具库中发现所需工具，再用 `call` 调用工具取数，即可使用 Wind 全部金融能力。

## 使用流程

在本 SKILL.md 所在目录运行 `node scripts/cli.mjs`（需要 Node.js 18+）。遇到新的数据需求，依次 search 找工具 → call 取数 → 展示结果，出错时按第 4 步处理；已找到的工具换个标的或时间仍适用时，直接 call。金融数据以返回结果为准，不用模型记忆补数。

## 第 1 步：search 找工具

```bash
node scripts/cli.mjs search "贵州茅台最新股价多少"
```

- 传要查的数据需求。用户原问句已写明标的和指标时，直接用原问句；追问省略了标的或指标时，补全成完整的一句，如上一轮问茅台股价、这一轮问「那五粮液呢？」，就搜「五粮液最新股价多少」。
- 一个问题里有几类数据（如股价和财报），每类分别 search；同一类数据涉及几个标的，search 一次即可。
- 返回候选工具表，不返回数据：`rows` 里每行一个工具，列名见 `columnNames`；`toolName` 是工具名，`score` 是匹配度，`description` 是功能说明，`params` 是参数定义。
- 选工具：先按 `score` 从高到低看，再逐个读 `description`，确认它覆盖要查的标的、指标和时间范围后再选用。候选都不合适时，把标的和指标说得更具体再搜，或用 `--top-k N` 多看几个（1–10，默认 3；每个候选都带完整参数定义，取得越多返回越长）。

## 第 2 步：call 取数

```bash
node scripts/cli.mjs call securities_get_price '{"windCodes":["600519.SH","000858.SZ"]}'
```

工具名后面跟一个 JSON 对象，就是这个工具的参数。

### 参数怎么填

- 工具名原样取自 search 结果的 `toolName`。
- 参数严格按该工具 `params` 的定义填写：先读完每个参数的描述，再按其中的类型、格式、约束和默认值填（如 `integer` 写不带引号的数字，`array` 写成数组，有 `enum` 的原样选一个）；`required` 里的必须填，其余按需要填，用不到的省略。
- 参数是数组的，多个标的放进同一个数组一次查完；只收一个标的的，每个标的各调一次。工具没有参数（`params` 里 `properties` 为空）时，只写工具名，后面不跟 JSON；写 `'{}'` 也可以。

### 命令行怎么写

- bash、zsh（macOS、Linux，以及 Windows 上的 Git Bash）：用单引号把标准 JSON 包起来，如上例。
- Windows 的 PowerShell 和 cmd 会吃掉 JSON 里的双引号，改成外层双引号、里面的字符串用单引号：

  ```powershell
  node scripts/cli.mjs call securities_get_price "{'windCodes':['600519.SH']}"
  ```

- 参数值和 search 的问题里尽量不带单引号、双引号和 `$`，标的写代码或中文名，如穆迪写 `MCO.N` 或「穆迪」。一定要带单引号时，任何 shell 都用外层双引号的写法，单引号写成 `\'`：

  ```
  node scripts/cli.mjs call general_query_data "{'question':'Moody\'s 最近 5 个交易日收盘价'}"
  ```

- 中文直接写。参数里的中文被执行器改成 `?` 或乱码时（如报错里回显的参数），把中文写成 `\uXXXX` 再试，如「贵州茅台」写成 `\u8d35\u5dde\u8305\u53f0`；search 的问题也可以这样写。
- 返回内容里的中文（如证券简称、列名）也是乱码时，是执行环境没按 UTF-8 读输出，改参数解决不了，如实告诉用户。

## 第 3 步：展示结果

成功时退出码为 0，CLI 把工具返回的原文（多为 JSON）整段输出；回答时摘取用户要的部分。

- 返回为空（如 `[]`）或只有「没找到数据」这类文字时，调用是成功的，只是这个工具没查到：换个工具或换个说法（选一种）再查一次，仍然没有就如实告诉用户查不到。
- 回答前核对返回数据里的标的代码和名称、数据日期、单位和口径；返回的标的与用户所指不一致时，向用户说明，不要当作所问标的作答。
- 只用返回里有的数据：缺失的照实说明，0 照实保留，单位以返回里标注的为准；多个标的只返回了一部分时，说明缺了哪些。
- 用到返回数据时，在回答末尾按回答的语言注明来源。中文回答写：数据来源于 Wind Alice 万得金融数据服务。英文回答写：Data sourced from Wind Alice Financial Data Service. 没用到返回数据（查不到、超出范围）时不写。

## 第 4 步：报错怎么办

失败时退出码为 1，输出一行 JSON：`ok` 为 `false`，`code` 是错误类别，`message` 写明原因和下一步怎么做。例如：

```json
{"ok":false,"code":"TOOL_ERROR","status":400,"message":"未识别到有效的金融标的:SMH.N；相近证券：SMH.O(VANECK半导体ETF)、SMH.L(VANECK半导体ETF)；请改用上述代码重试或向用户确认"}
```

错误种类很多，统一按 `message` 处理：

1. message 给了改法（改参数、换代码、换工具、重新 search、换命令写法等）：照做后重试。
2. message 要求停止或稍后再试，或原因在调用之外（次数或积分用完、没有权限等）：停止调用，把原因和建议如实告诉用户。
3. 按 message 改过一次仍然失败，或 message 没给改法、换个说法或换个工具（选一种）再试一次仍然失败：停止重试，如实告诉用户。
4. `code` 为 `AUTH_ERROR` 是认证失败（API Key 未配置、无效或过期），按注意事项里的「API Key」处理；`code` 为 `PERMISSION_DENIED` 是账号没有权限，Key 本身没问题，不用重新配置 Key。

取不到的数据不用模型记忆补。message 里的 market_search_tools、market_call_tool 指本 CLI 的 search、call。

## 注意事项

- **运行目录**：命令在本 SKILL.md 所在目录运行，不是当前项目目录。
- **API Key**：有没有配置 Key，以实际调用的结果为准。报 `AUTH_ERROR` 时，运行 `node scripts/cli.mjs open-portal`，它会在浏览器打开用户页面，打不开时输出里有网址，把网址发给用户；请用户登录后复制 API Key，用户提供后，运行 `node scripts/cli.mjs setup-key <KEY>` 写入，再重试原命令。回答里不展示完整的 Key。
- **异常值**：返回 0 或明显不合理的值（如国债收益率为 0），可能是数据缺失，照实给出并说明；单位、量级没标注时，照原值给出并说明未标注，不自行换算。
- **长输出**：结果很长时，宿主可能把输出存成文件、只显示开头一段，读完整个文件再作答。
