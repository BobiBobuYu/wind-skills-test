# `fund_data` 行情指标

仅供 `get_fund_price_indicators` 的 `indexes` 使用。指标名称来自线上工具定义，逐字复制并用英文逗号连接；未指定字段时省略 `indexes`。工具列出的字段不代表适用于所有市场或标的，空值与不适用项按实际返回处理。

默认字段：`最新交易日,交易时间,最新成交价,前收盘价,今日开盘价,今日最高价,今日最低价,成交量`。
