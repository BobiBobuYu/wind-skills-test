# 历史走势与分页

`securities_get_trend` 查询单个标的，必填 `windCode`、`startDate`、`endDate`，日期为 YYYY-MM-DD。相对时间按当前日期和用户语境转换成区间。

线上工具描述明确每页最多最近 250 个交易日。首页使用原开始日与截止日；需要更早数据且 `hasMore=true` 时，保持原 `startDate`，将 `endDate` 改为返回的 `nextEndDate`。`hasMore=false` 时分页结束，`nextEndDate` 可以省略。

按返回日期筛选原请求区间；非交易日起点可能带出此前交易日。分页后按标的和日期去重、排序，并核对实际覆盖范围。`dates` 与 `series` 结构按相同下标读取；表格结构按实际列名读取。

游标应向过去推进，避免重复页或倒序日期请求。缺少必要分页信息或某页失败时，保留已取得的数据与缺口，按主文件的恢复规则处理；不将单页或部分结果称为完整区间。

本工具未声明 period、aftype、count、indexes 或分钟分时参数。明确需要周期、复权或分钟行情时，使用对应资产的专项工具；替代取数按实际口径说明。
