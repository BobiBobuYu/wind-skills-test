# 全球行情与证券服务工具契约

本文件于 2026-10-15 对照线上 `tools/list` 与实测回执核对。调用方式、User-Agent 与错误恢复见主文件。

## 公共规则

- 参数名区分大小写。`securities_get_price` 使用 **`windCodes: string[]`**；`securities_get_financials`、`securities_get_trend`、`securities_get_profile` 使用 **`windCode: string`**，查询单个标的。
- 身份明确时直接查询，不强制 lookup。代码例子只展示格式，不可据此猜测其他标的的后缀。
- 服务支持的品种不等于每个标的、字段、历史时点都可返回；以实际结果为准。
- `securities_get_price` 数组至少 1 项、最多 50 项且不重复；单标的同样传数组。MCP 入参保持数组，服务端适配层负责拼接逗号字符串。其他参数按各工具的 schema 填写。

## `securities_entities_lookup`

| 参数 | 必填 | 类型 | 约束 |
| --- | --- | --- | --- |
| `keyword` | 是 | string | 名称、简称或关键词 |
| `maxCount` | 否 | integer | 1–20，省略默认 5 |

```json
{"keyword":"茅台","maxCount":5}
```

仅在其他工具识别失败、返回身份不符或候选歧义时使用。返回代码、名称、参考分类，可能多候选或为空；分类需结合代码和数据工具的身份信息核对。不是筛选证券列表的工具；空结果不能否定准确代码取数能力。

实测正文为 JSON，候选在 `list` 数组中，每条记录包含 `category`、`name`、`windCode`。

## `securities_get_price`

| 参数 | 必填 | 类型 | 约束 |
| --- | --- | --- | --- |
| `windCodes` | 是 | array<string> | 1–50 个不重复的代码/名称；覆盖服务支持的股票、基金、指数、可转债、期货或外汇 |

```json
{"windCodes":["600519.SH","000300.SH","USDCNY.IB"]}
```

单标的示例：`{"windCodes":["600519.SH"]}`。支持混合资产批量快照，返回按每条记录的代码与单位解释。

实测正文为 `data` 记录数组，每条记录带 `windcode`、`indicator_units`；按代码对应请求标的，逐条读取单位和交易时点。涨跌幅单位为 `1%` 时，值 `0.87` 表示 `0.87%`。

示例代码：ETF `510300.SH`、场外基金 `000001.OF`、指数 `000300.SH`、可转债 `113707.SH`、外汇 `USDCNY.IB`。这些例子来自服务契约，具体可用数据仍依返回结果判断。

返回最新可用行情快照及品种可提供的指标。股票成交价、指数点位、场外基金净值/收益类指标和外汇汇率不是同一口径。不保证实时或查询当日，不能保证所有品种均有成交量额/资金流；不提供估值。区间涨跌幅不能当逐日价格序列。外汇须明确货币对、方向和市场，可转债优先用准确代码。

## `securities_get_financials`

| 参数 | 必填 | 类型 | 约束 |
| --- | --- | --- | --- |
| `windCode` | 是 | string | 单只股票代码/名称 |

```json
{"windCode":"600519.SH"}
```

返回财务科目、报告期及跨期记录，覆盖服务提供的收入、利润、资产负债、现金流、每股指标及财务比率。仅股票；查可转债发行人财务时先明确发行人对应股票，再传股票代码。不能传基金、指数、可转债、期货或外汇。

不支持额外的日期、频率或指标筛选参数，不保证完整三大报表。用户指定 2024 年净利润等条件时只传 `windCode`，从返回记录中选择正确报告期和科目；若未覆盖则说明。实际期与预测期不可混用。

实测正文为 Markdown 表格：表前带证券代码、币种与金额单位，行是科目、列是报告期，预测列带“盈利预测”等标记。比例、每股等科目不能一律套用表头的金额总额单位；单位不明时说明。未覆盖的目标科目或报告期可用 stock_data/get_stock_fundamentals 补取。

## `securities_get_trend`

| 参数 | 必填 | 类型 | 约束 |
| --- | --- | --- | --- |
| `windCode` | 是 | string | 服务覆盖的单个股票、基金、指数、可转债、期货或外汇代码/名称 |
| `startDate` | 是 | string | 有效自然日 `YYYY-MM-DD`，不得晚于 `endDate` |
| `endDate` | 是 | string | 同格式；首页原截止日，更早页只采用返回的 `nextEndDate` |

```json
{"windCode":"000300.SH","startDate":"2026-09-01","endDate":"2026-09-30"}
```

返回历史价格、价量或基金单位/累计净值等序列。每页最多最近 250 个交易日；非交易日起点可能带出此前交易日。**调用此工具时至少核对原区间、身份、`hasMore`；需要完整长区间时读 [trend.md](trend.md)。**

实测正文包含 `windCode`、`securityName`、`dates`、`series`、`hasMore`；`dates` 为 `YYYYMMDD` 字符串，`series` 各字段数组与日期按相同下标对应，先核对长度，再按原请求区间筛选。

不支持 `period`、`aftype`、`count`、`indexes` 或分钟分时，不能承诺复权口径。返回已有字段足以支持用户要求时可本地计算收益/技术指标；说明输入序列、算法和已知口径，缺少复权等信息会影响的分析要注明限制。

## `securities_get_profile`

| 参数 | 必填 | 类型 | 约束 |
| --- | --- | --- | --- |
| `windCode` | 是 | string | 单个股票、基金、指数或期货代码/名称 |

```json
{"windCode":"510300.SH"}
```

- 股票：公司简介、主营、行业、实际控制人、第一大股东等基础资料；不等于完整股东历史/明细。
- 基金：管理人、托管人、运作方式、投资范围、业绩比较基准及申赎安排；投资范围不是实际持仓。
- 指数：基日、基点、发布机构、加权方式、成份数量；数量不是成份名单。
- 期货：交易所、合约规模、报价单位、最小变动、交易时间和交割规则；标准规则不能代替具体合约当前保证金/手续费。

不支持可转债或外汇。某标的能够返回价格不意味着基础资料也可用。

实测正文包含 `windCode` 及 `items` 数组，资料按条目的 `name`、`value` 读取；部分条目没有 `value`，按缺失处理。
