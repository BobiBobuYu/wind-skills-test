# `economic_data` 工具契约

只用于宏观、行业和汇率 EDB 指标。参数名、类型、默认值及枚举以下方线上定义为准。

- 找指标或确认代码用 `search_economic_indicator`，取具体数值序列用 `query_economic_indicator_data`。
- 查询序列时填写用户指定的 `beginDate` + `endDate`，或整数 `observation`，两种方式互斥。2026-10-14 实测只传 question 被后端拒绝（必须填写期数或日期）；最新一期需求可传 observation=1。错误文案写 startDate，但入参仍使用 schema 中的 beginDate。
- `targetMagnitude`、`targetFrequency`、`targetCurrency` 用于工具已支持的数量级、频率与币种转换。需要比较或换算时按契约填写，单一指标原口径查询时省略。
- `targetMagnitude` 的说明举例包括“亿元”等组合单位，但枚举为“亿”等数量级词；入参逐字使用枚举，不把组合单位直接填入。
- `observation` 按最低频率指标对齐时间跨度，不保证每个频率恰好返回 N 条；按目标指标频率、实际日期及条数核验。
- 指标元信息与序列返回中的单位、量级、币种及频率用于解释数据；不能用数据条数或默认口径替代用户指定的时间范围。

## 工具契约

### `search_economic_indicator`

根据自然语言需求，从经济数据库中检索并匹配相关经济指标，返回指标的元信息（指标名称、指标代码、频率、单位、来源等），不提取指标数据。适用于查找可用指标、筛选指标及提数前确认指标的场景。

### `query_economic_indicator_data`

用于自然语言获取 Wind EDB 宏观经济指标信息和时间序列数据（不回答概念、定义等无需访问 EDB 数据的问题）。当用户明确要求换算，或语境隐含需要将多个指标放同一口径下比较（如跨国/跨地区对比、统一看板、计算差值、排名等）时，需填写 targetMagnitude、targetFrequency、targetCurrency 参数，工具会在输出时间序列数据时自动转换并对齐数据。
